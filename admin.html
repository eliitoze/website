➕ How to Add a New Product

GitHub Pages is a static website. Server-side upload possible નથી.
Products add કરવા માટે GitHub repository directly edit કરો:

📋 Step-by-Step Process:
  1. GitHub repository open કરો
  2. images/ folder માં product photo upload કરો (e.g. product7.jpg)
  3. videos/ folder માં product video upload કરો (e.g. product7.mp4)
  4. products.js file edit કરો અને નવો product add કરો
  5. Commit & Push કરો → website automatically update થશે
📝 products.js માં product format:
{ id: 7, name: "Your Product Name", price: 2000, discountPrice: 1799, // 0 means no discount image: "images/product7.jpg", video: "videos/product7.mp4", qty: 10, description: "Short description here" },
💡 Video Tips:
• Video 5-10 seconds રાખો
• Upload પહેલા compress કરો (HandBrake app free છે)
• File size 5MB થી ઓછી રાખો fast loading માટે
• Format: MP4 (H.264) recommend
